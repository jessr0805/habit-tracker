# Habit Tracker
A Python-based habit tracker built for all users, whether they are looking for a minimalistic way to track their habits, or users just wanting to have fun.
## Cool Features 
- **Streak Counter**
- **Automatic Export to JSON**
- **Session Sync**
## How to Run It
Ensure Python is installed
If it isn't visit the 
[Official Python Installer Link](https://www.python.org/downloads/)
To run the tracker directly in the terminal,
- Clone the repository
- Navigate to the repository in your terminal
- Run
  ```bash
  python habitrack.py
  ```
